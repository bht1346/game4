武器管理

整合包文件格式说明（点开）

文件后缀

.json，UTF-8 纯文本。导入后存进浏览器本地（换设备或清缓存会丢，可用「清除」按钮清掉）。

两种写法都认

{ "name": "整合包名", "weapons": [ {...}, {...} ] }   整合包（推荐）
[ {...}, {...} ]                                      散装枪，会归到「未归类武器」

一个整合包 = 一个包名 + 若干把枪。设置里按包分组显示，可整个包一起删除。

整合包字段

name     包名（必填）   desc 说明   version 版本号
code     兑换码（选填）写了就整包锁定，别人必须输对码才能用
         也可以写数组： "code": ["AAA-111", "BBB-222"] 多个码任选其一
         不区分大小写，前后空格自动去掉

枪的通用字段

name     名称      必填 1-12 字，没有这行整把枪被丢弃
dmg      单发伤害  1 - 2000        默认 20
cd       射击间隔  30 - 3000 毫秒  默认 200（越小越快）
speed    子弹速度  2 - 60          默认 12
spread   散布角度  0 - 60 度       默认 0
pellets  每发弹丸  1 - 12          默认 1
zoom     视野倍数 1 - 5            默认 1（>1 = 缩小画面，看到的区域更大）
color    子弹颜色  #ffcc33 或 red，默认 #ffcc33
pierce   穿透层数  0 - 10          默认 0（狙击穿甲用）

behavior：决定这把枪的手感

plain          普通：按下即射，可连发
charge_sniper  蓄力狙击：同霰弹手感，按住缩视野、锥形由大收小，伤害更高且可穿甲
choke_shotgun  收束霰弹：按住越久弹道越收拢，松手一次性打出去

没写 behavior 就是 plain。写了不存在的名字会自动退回 plain。

fireMode：什么时候打出去

press     按下即射（可连发）
release   松手才射（蓄力类默认这个）

游戏里也能改：点枪名选中 → 展开的小面板里切换。

蓄力狙击专属：charge（与霰弹 choke 同一套）

"charge": { "chokeMs": 1200, "spreadFrom": 20, "spreadTo": 2,
                       "rangeMax": 1600, "span": 0.95 }   // span=瞄准线占屏比例
按住 1200 毫秒内，锥形瞄准从 20° 收到 2°；rangeMax 是最大射程
zoom 填 2.6 就是按住时画面缩到 1/2.6，看到的区域变大 2.6 倍

收束霰弹专属：choke

"choke": { "chokeMs": 1200, "spreadFrom": 18, "spreadTo": 4 }
按住 1200 毫秒内，散布从 18° 收到 4°

规划中：写了会保存，暂时不改变手感

icon / sprite  贴图路径（后面上贴图就靠这两个）
recoil   后坐力      ammo   弹匣容量     reload 换弹时间
range    有效射程    explosive 爆炸半径
sound    音效文件    note   备注

填错了会怎样

超范围自动夹到边界（dmg 填 99999 变成 2000）；非数字退回默认值；没有 name 的枪直接丢弃； 空包直接丢弃。不会因为一把坏枪搞崩游戏。建议先点「下载模板」改数值。

完整示例（一个包含三把枪的整合包）

{
  "name": "我的整合包",
  "desc": "一把步枪一把狙一把霰弹",
  "version": "1.0",
  "weapons": [
    {
      "name": "连发弩", "dmg": 18, "cd": 90, "speed": 22,
      "spread": 2, "pellets": 1, "zoom": 1.5, "color": "#88ff66",
      "behavior": "plain", "fireMode": "press"
    },
    {
      "name": "穿甲狙", "dmg": 150, "cd": 1200, "speed": 34,
      "spread": 0, "pellets": 1, "zoom": 3, "color": "#66ddff",
      "behavior": "charge_sniper", "fireMode": "release",
      "pierce": 2, "charge": { "chokeMs": 1200, "spreadFrom": 20, "spreadTo": 2,
                       "rangeMax": 1600, "span": 0.95 }   // span=瞄准线占屏比例
    },
    {
      "name": "收束霰弹", "dmg": 12, "cd": 700, "speed": 11,
      "spread": 18, "pellets": 8, "zoom": 1, "color": "#ff9944",
      "behavior": "choke_shotgun", "fireMode": "release",
      "choke": { "chokeMs": 1200, "spreadFrom": 20, "spreadTo": 5 }
    }
  ]
}
自定义武器存在浏览器本地，换设备/清缓存会丢失。
